# 資格学習（資格取得アプリ）

4択演習・○×一問一答・復習（忘れかけた頃に出題）・科目別の正答率・試験日までの残り日数を備えた、資格試験向けの学習アプリ。
画面は1つのWebアプリ、問題は資格ごとのJSON（`data/`）に分けてある。最初の資格は宅建。仕様は `docs/設計.md`。

## 起動

いちばん簡単なのは `PCで試す.bat` をダブルクリック（サーバーが起動し、2秒後にブラウザが開く。黒い窓を閉じると止まる）。

コマンドで起動する場合:

```
python tools/devserver.py        # http://127.0.0.1:8790/ （ゴルフナビの 8765・8770 とは別のポート）
```

ブラウザで開く。`npm run serve` でも同じ。止めるときは Ctrl+C。外部ライブラリ・CDN は使っていない。

## テスト

```
npm test        # node --test tests/*.test.mjs（過去問取り込みツールの Python テストも tests/python.test.mjs から一緒に走る。Python が無いとその1件だけ飛ばす）
```

画面のファイル（js・css・html・icons・sw.js）を変えたのに版を上げ忘れると、`tests/version.test.mjs` が失敗する。

## 版の上げ方

```
npm run bump            # 0.1.0 → 0.1.1
npm run bump 0.2.0      # 版を指定
```

`js/version.js`・`sw.js`・`version-lock.json` が一度に更新される。`data/` の中身だけを変えたときは上げなくてよい
（問題データは常に最新を取りに行く）。ただし `data/` にファイルを足したら `sw.js` の `APP_FILES` にも足す（`tests/data.test.mjs` が確かめる）。
`js/` にファイルを足したときも同じ。

## 問題データの置き方

- `data/index.json` … 資格の一覧。`data/<資格ID>/exam.json` … 資格の定義。`data/<資格ID>/q-<科目>.json` … 問題。
- 形の検査は `js/store.js`（`validateExam` / `validateQuestionFile` / `validateQuestion`）。`npm test` でも `data/` 全体を検査する。
- 4択の正解番号はデータに持たない。`pick`（任意。true=正しい／適切なものを選ぶ、false=誤り／不適切なものを選ぶ）と、各選択肢の `ok`（記述そのものが正しいか）から計算する。`pick` が無ければ `ask`（「正しいもの」「誤っているもの」「適切なもの」「不適切なもの」など）から推定する。どちらでも決まらない問題は不正データ。
- **公開後は選択肢の順番を変えない。** ○×の記録は `問題id#選択肢番号` で持つため、順番を変えると過去の記録がずれる。直したいときは新しい id の問題にして、旧問題を `status: "retired"` にする。
- `exam.maxPoints`（任意）は満点。無ければ問題数（1問1点）。合格目安の検査と表示に使う。
- `reviewed: false` の問題には、画面に「未確認」バッジが出る。人が条文で確かめたら `true` にする。
- 問題の型は `choice`（4択）・`single`（個数・組合せなど。正解の番号 `answer` を持つ）・`truefalse`（○×）。任意の `basisText`（根拠条文の本文）は、回答後の解説の下に「条文を見る」で表示する。
- **公開してよいのは、自作と、確認済みの問題だけ。**
  過去問（`source.kind` が `past-exam`）は公開フォルダ `data/` に置かない（置くと `npm test` が失敗する）。
  過去問や市販問題集は `private/` に置く（`.gitignore` で Git に入らない）。
  使うときは、アプリの 設定 → 「自分の問題の取り込み」 でそのJSONを選ぶ。検査したうえでこの端末の中だけに保存し、外部には送らない。
  取り込む問題の id は `<資格ID>-<科目ID>-p<4〜8桁>`（例 `takken-kenri-p0001`、過去問は `takken-kenri-p202501`）の形だけ。公開データの id（pなし）とは形が違うので衝突せず、公開データの形の id を持つファイルは理由つきで断る。
  ファイルは UTF-8 で保存する（Shift-JIS だと文字化けを検知して止める）。削除も設定画面でできる。

## 過去問を取り込む手順（RETIO の PDF → 自分の端末だけで使う）

1. 過去問のPDFを自分でダウンロードして `private/` に置く（Git に入らない。公開しない）。
2. `python -I tools/import-retio.py private/R7.pdf --out private/takken-R7.json`（令和7年度。`--year 2025` は省ける＝表紙の年度から決める。付けて表紙と違えば止まる）。PyMuPDF が必要。正解表が50個読めなければエラーで止まり、何も出力しない。最後に件数・noTf（○×に出さない問題）・警告の一覧が出る。
3. `node tools/check-private.mjs private/takken-R7.json` で形を確かめる。
4. アプリの 設定 → 「自分の問題の取り込み」 でそのJSONを選ぶ。
5. 条文を問題に足すなら `node tools/egov.mjs 宅建業法 35 6`（e-Gov 法令API。手で動かしたときだけ通信）。出たJSONを `basisText` に足す。
6. 解いたあと「確認済みにする」「誤りかも」で印を付ける（端末内に保存。書き出しにも入る）。

詳しくは `docs/問題作り.md`。

## 手で確かめること（自動テストでは確かめられない）

- **保存の版上げ（DB v1 → v2）**: 古い版（v0.1.1 以前）のページを一度開いて学習記録を数件つくる → 新しい版に切り替える（再読み込み）→ 設定画面で「いまの記録」の件数が減っていないこと、「確認の印」が 0 件で表示されることを確かめる。
- **複数タブ**: 古い版のタブを開いたまま、新しい版のタブを開く → 新しいタブに「古い版のタブが保存を使っているため…ほかのタブを閉じてください」と出る。古いタブを閉じると自動で続きが動き、記録が読み込まれる。逆に、新しい版が動いている間に古いタブが開こうとすると、新しいタブ側に「ほかのタブで更新されました。再読み込みしてください」と出る。
- **書き出し**: スマホで「ファイルに書き出す」→ 共有の画面で保存先を選べること。やめたら「最後の書き出し」が更新されないこと。

## 学習記録

- 復習の箱の進み方: 不正解は箱1・翌日。正解は、初回か次回期限の日以降のときだけ箱を1つ進める（期限前の正解は据え置き）。詳しくは `docs/設計.md`。
- 回答1回ごとに1件足すだけ（`{ id, itemId, examId, at, correct, mode, device }`）。端末内の IndexedDB に保存する。
  復習の箱（1・3・7・14・30日）や正答率は、毎回この記録から計算する（`js/progress.js`）。
- 確認の印（「確認済み」「誤りかも」）も同じ形で追記して保存し、書き出し・読み込みに含める。
- 設定画面で書き出し（JSON）・読み込み（id で重複を除いて足す）ができる。別の端末の記録を合わせるときにも使う。
  最後の書き出しから14日以上たつと、ホームで促す。書き出しは、共有（保存先を選べる）が使えればそれを優先し、保存できたと分かったときだけ「最後の書き出し」を更新する（ダウンロードのときは「保存できましたか？」で確認）。
- 端末名・試験日と合格目安の上書き・選択中の資格は localStorage に保存する。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` / `css/style.css` / `js/app.js` | 画面 |
| `js/store.js` | データの読み込みと形の検査、正解の計算、private の取り込み判定 |
| `js/progress.js` | 学習記録・復習の箱・マージ・正答率（画面に依存しない） |
| `js/quiz.js` | 出題キュー・○×項目の作成・採点 |
| `js/stats.js` | 科目別の表・残り日数・書き出しを促す条件 |
| `js/db.js` | IndexedDB / localStorage への保存 |
| `sw.js` / `js/pwa.js` / `js/version.js` | 圏外でも動く仕組みと版ずれの検知 |
| `tools/` | `release.mjs`（版）、`devserver.py`、`make-icons.mjs`（アイコン）、`import-retio.py`（過去問PDF→取り込みJSON）、`import-retio-ocr.py`・`ocr-diff.py`・`winocr.ps1`（画像だけのPDFの書き起こし→取り込みJSON。手順は docs/問題作り.md）、`check-private.mjs`（取り込みJSONの検査）、`egov.mjs`（e-Gov から条文を取る） |
